# 计划：让 Bot 学会用弓/弩远程战斗（待讨论，未实装）

> 状态：仅讨论计划。此前误实装的远程战斗代码已退回，本项目不包含以下功能的实现。

## 目标
让 AI 在判断「远程更合适」时，能用弓/弩射箭打怪（苦力怕、凋灵、骷髅、末影龙等），并能根据战况在近战/远程之间自动切换。

## 现状（已核实）
- 合成：Bot 已能通过通用 `craft_item` 合成弓（3 线+3 木棍，3×3）、弩（木棍+线+铁锭+绊线钩，两步）、箭（燧石+木棍+羽毛）。所以「会不会合成」不是问题。
- 战斗：目前只有近战（`attack_hostile`/`hunt_entity` 挥剑）。武器选择只认剑/斧，不认弓弩；没有拉弓/装填/射箭逻辑，也没有箭矢管理。

## 用户提议的脚本化设计
1. **选择目标脚本**：自动选择目标，当前目标死亡/脱离后自动切换攻击目标。
2. **稳定瞄准脚本**：锁定目标瞄准（需处理提前量 + 弹道下坠）。
3. **实时监听箭矢总数**：每 tick 统计背包 `minecraft:arrow`，为 0 时停用远程。
4. **激活/停用**：AI 判断更适合远程时激活上述脚本；判断不需要远程或没箭矢时停用并退回近战。

## 近战/远程切换速度（后续讨论重点）
问题：若每次近战↔远程切换都等模型响应（一趟 LLM 往返数秒），怪多时太慢。
优化方向：把「用近战还是远程」的决策下沉到客户端本地（Java 每 tick 判定，不经过模型）。
- 方案：新增一个「持续战斗」动作，模型只调用一次；进入战斗后，客户端每 tick 用规则决定近战还是远程：
  - 危险怪（苦力怕/凋灵/末影水晶/守卫者/烈焰人/幻翼等）且在射程内、有箭、有弓 → 远程；
  - 否则 → 近战；没箭/没弓自动退回近战；目标死亡自动切换。
- 好处：面对一堆怪时近战/远程瞬间切换，不用等模型。
- 保留「纯远程」「纯近战」动作供模型明确指定。

## 放箭提前量（后续讨论重点）
提前量需综合考虑多个因素（不能用简单速度×固定时间）：
| 因素 | 处理 |
| --- | --- |
| 射程/弓速 | 满弓箭速约 60 格/秒（弓/弩接近） |
| 距离 | 飞行时间 = 距离 ÷ 箭速（封顶防远距过冲） |
| 怪物移速 | 取 `target.getDeltaMovement()` 矢量 |
| 怪物移动方向 | 提前量 = 移动矢量 × 飞行时间（横向 `motion.x/z`） |
| 垂直移动 | 加 `motion.y` 提前量（烈焰人/幻翼等） |
| 重力下坠 | 抛物线补偿 `0.5 × g × t²`，瞄高一点（g≈20 格/秒²） |

## 难度评估（大白话）
- 合成：难度 ≈ 0（已会）。
- 站桩射固定目标：中低，一两天能做出可用版本。
- 稳定命中移动怪：中高，卡在弹道提前量。
- 近战/远程聪明切换 + 弹药管理：中等，是规则不是技术难题。

## 待实机调优项
- 重力下坠系数（当前按 20 格/秒² 常识值）。
- 「危险怪清单」（creeper/wither/guardian/ghast/phantom…）。
- 弹道命中率需进游戏实测调参。
